# Java + JDBC + Node.js + HTML Full Stack Application

Ready-to-run Student Management System.

Stack:
- HTML/CSS/JavaScript frontend
- Node.js/Express frontend server and API proxy
- Java backend REST API
- JDBC for database access
- Embedded H2 database, so no MySQL credentials are required

Requirements: Java JDK 17+, Maven 3.8+, Node.js 18+.

Run Java backend:
- Windows: run-backend.bat
- Linux/macOS: ./run-backend.sh

Run frontend:
- Windows: run-frontend.bat
- Linux/macOS: ./run-frontend.sh

Then open http://localhost:3000

Features: add students, list students, delete students.
